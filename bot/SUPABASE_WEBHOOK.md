# اتصال امن ربات تلگرام خبر رادین به Supabase

## وضعیت
تابع `radin-telegram-webhook` در پروژه Supabase فعال است. آدرس:
`https://gtbrkufbsllbosdyogfx.supabase.co/functions/v1/radin-telegram-webhook`

این تابع به توکن ربات و یک رمز وب‌هوک نیاز دارد که باید در Supabase Secrets تنظیم شوند. هیچ توکنی را در GitHub یا گفتگو ذخیره نکنید.

## 1. چرخش توکن
توکنی که قبلاً در گفتگو افشا شده را در BotFather با دستور `/revoke` لغو کنید و توکن جدید بگیرید. توکن جدید را فقط در Supabase > Edge Functions > Secrets (یا تنظیمات Secrets پروژه) به نام `BOT_TOKEN` ثبت کنید.

## 2. افزودن Secrets
در همان بخش Secrets این مقادیر را اضافه کنید:
- `BOT_TOKEN`: توکن جدید BotFather
- `TELEGRAM_WEBHOOK_SECRET`: یک رشته تصادفی محرمانه، حداقل 32 کاراکتر، فقط با حروف انگلیسی و اعداد و زیرخط
- `ADMIN_USER_IDS`: شناسه عددی مدیر، مثلاً `9129058355`

رمز وب‌هوک را در مخزن کد یا پیام عمومی قرار ندهید.

## 3. ثبت وب‌هوک تلگرام
پس از ثبت Secrets، آدرس تابع بالا را به عنوان Webhook URL در Telegram Bot API ثبت کنید و همان مقدار `TELEGRAM_WEBHOOK_SECRET` را در پارامتر `secret_token` بفرستید. این کار باید با توکن جدید انجام شود؛ توکن را در مرورگر مشترک، GitHub یا گفتگو قرار ندهید.

## 4. آزمون
در چت خصوصی با ربات:
- `/start`
- `/help`
- `/categories`
- `/status` (برای مدیر)

پاسخ موفق به این دستورها فقط اتصال پایه را تأیید می‌کند؛ هنوز به معنای فعال بودن جمع‌آوری خبر یا انتشار خودکار نیست.

## محدودیت فعلی
تابع فعلی فقط دستورهای پایه را پاسخ می‌دهد. هنوز به کانال‌های منبع متصل نشده، بازنویسی هوش مصنوعی ندارد، خبر حساس را برای تأیید ذخیره نمی‌کند و خبر منتشر نمی‌کند. قبل از انتشار خودکار باید منطق صف خبر، حذف تکراری، کنترل منبع، تأیید انسانی و ثبت گزارش اضافه و آزمایش شود. تابع RSS موجود `rss-ingest` جداگانه است و نباید بدون بررسی جایگزین شود.
